## Upgrade Instructions

Follow these steps to upgrade smoothly.

<Steps>
  <Step title="Backup Your Data" icon="database">

    Create a full backup before proceeding.

````bash
# Example backup command
pg_dump -U user vijaybharadwaj_db > backup.sql
````

  </Step>
  <Step title="Update Package" icon="download">

    Install the latest version.

    <CodeGroup tabs="npm,yarn">
````bash
npm install vijay-bharadwaj@latest
````
````bash
yarn add vijay-bharadwaj@latest
````
    </CodeGroup>

  </Step>
  <Step title="Run Migrations" icon="settings">

    Execute database migrations.

````bash
npm run migrate
````

  </Step>
  <Step title="Restart Service" icon="refresh-cw">

    Restart your application server.

  </Step>
</Steps>

<Expandable title="Detailed Migration Guide" default-open="false">
  For v1.0.0 to v1.2.0 upgrades, review these changes:

  | Old Config | New Config | Action |
  |------------|------------|--------|
  | `api.host` | `api.endpoint` | Update key |
  | `db.url`   | `database.url` | Rename |
  | `debug: true` | `logging.level: "debug"` | Restructure |

  Run the migration script:

````bash
node migrate-config.js --from v1.0.0 --to v1.2.0
````
