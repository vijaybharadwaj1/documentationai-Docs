## Overview

Getting started is simple:

1. Sign up at `https://vijaybharadwaj.com/join`
2. Log in to your dashboard
3. Click "New Project" to create documentation
4. Use the editor to add, edit, or organize docs
5. Invite team members as collaborators

## Quick Tips
- Use folders to organize docs
- Access recent changes from your dashboard
- Export docs as PDF or Markdown anytime
