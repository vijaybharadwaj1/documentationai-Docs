## Document Organization

Organize your documentation into logical structures using folders and pages. Start by creating a main folder for your project, then add subpages for guides, APIs, and FAQs.

<Steps>
  <Step title="Create a Folder" icon="folder-plus" title-type="p">
    Navigate to your workspace and click the new folder button. Name it after your project, like `Vijay Bharadwaj Docs`.
  </Step>

  <Step title="Add Pages" icon="file-plus" title-type="p">
    Inside the folder, create pages for specific topics. Use the page editor to add markdown content.
  </Step>

  <Step title="Nest Subpages" icon="chevron-down" title-type="p">
    Drag pages under others to create hierarchies. This builds a clean navigation tree.
  </Step>
</Steps>

<Callout kind="tip" collapsed="false">
  Use consistent naming conventions like `01-quickstart.mdx` to auto-sort pages chronologically.
</Callout>

## Collaboration Workflows

Invite team members to collaborate in real-time. Assign roles like editor or viewer to control access.

<Tabs>
  <Tab title="Team Editing" icon="edit-3">
    Share a link to your doc. Collaborators see live cursors and can suggest changes.

    ```javascript
    // Example: Embed collaboration in your app
    const docId = 'project-docs-123';
    embedEditor(docId, { mode: 'collaborative' });
    ```
  </Tab>

  <Tab title="Review Process" icon="eye">
    Enable comments and @mentions. Reviewers add feedback without altering the original.

    <CodeGroup show-lines="true">
      ```markdown
      @team-review This section needs examples.
      ```

      ```javascript
      postComment('team-review', 'This section needs examples.');
      ```
    </CodeGroup>
  </Tab>
</Tabs>

## Search Functionality

Search across all docs with full-text indexing. Filter by folder, date, or author for precise results.

<Steps>
  <Step title="Basic Search" icon="search" title-type="p">
    Type keywords in the global search bar. Results appear instantly.
  </Step>

  <Step title="Advanced Filters" icon="filter" title-type="p">
    Add filters like `folder:guides author:you` for targeted queries.
  </Step>

  <Step title="Saved Searches" icon="bookmark" title-type="p">
    Pin frequent searches to your sidebar for quick access.
  </Step>
</Steps>

<Callout kind="info" collapsed="false">
  Search supports code syntax highlighting in results. Use `<code>query</code>` for exact matches.
</Callout>
